Arimo Regular and Bold are bundled for consistent monitor text on Windows and
Linux. Arimo has Arial-compatible metrics; Scratch requests Helvetica/Arial.

Source: https://github.com/googlefonts/arimo/tree/main/fonts/ttf

Copyright 2026 The Arimo Project Authors. Distributed under the SIL Open Font
License 1.1; see [OFL.txt](OFL.txt). The fonts are unmodified.

SVG costume text also uses these fonts as a portable fallback. The unmodified
Knewave font implements Scratch's `Marker` family, as mapped by
[scratch-render-fonts](https://github.com/scratchfoundation/scratch-render-fonts/blob/ec66ca1c4ec272abfc54ea9c4c37cfbfd96ed2ac/src/index.js).

Knewave source: [pinned font](https://github.com/scratchfoundation/scratch-render-fonts/blob/ec66ca1c4ec272abfc54ea9c4c37cfbfd96ed2ac/src/Knewave.ttf).
